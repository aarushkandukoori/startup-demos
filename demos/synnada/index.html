Symmetric Hash Join Playground

Two unbounded, out-of-order event streams run through a symmetric hash join in your browser: tune the join window and the watermark, and watch buffered state get evicted by a bound derived from the join predicate itself — or watch recall fall when the watermark is too aggressive.

The bounds are solved from the ON clause: a future shipment row cannot arrive before watermark(shipments), so an order whose window closes before that watermark can never match again and is safe to drop. Symmetrically, a shipment older than watermark(orders) can never find a future order, because the filter requires s.ts >= o.ts.

Missed vs batch compares the streaming output against a plain batch scan of the same synthetic rows, counted only once both sides of a pair have been ingested. It is zero whenever the watermark delay is at least the stream's disorder — the buffered-row saving is then free.

Query

The BETWEEN interval in the ON clause. Widening it admits more true matches and forces a larger buffer.

Event time

Watermark = max event time seen on that side minus this delay. Set it below the stream disorder and the watermark starts lying: rows get evicted before their partner shows up, and missed vs batch climbs.

How far behind its event time a row may arrive. Regenerates the ingest order of the same rows.
