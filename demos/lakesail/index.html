DataFrame Plan Optimizer Playground

Write a PySpark-style DataFrame program. This page parses it, resolves it against a synthetic Parquet-shaped catalog, optimizes the plan, and then executes it twice in your browser — once with a vectorized batch-at-a-time engine, once with a row-at-a-time interpreter — so you can watch each optimizer rule change the bytes read and the wall time.

query engines columnar synthetic data

An independent mini-demo built by Aarush Kandukoori, inspired by LakeSail's public product description. Not affiliated with LakeSail.

              Both engines run the same optimized plan on the same data. Each is
              timed with performance.now() over repeated rounds —
              enough runs per round to clear the clock's resolution — and the
              fastest per-run time is reported. This is JavaScript in your
              browser, so treat the ratio as the signal and the absolute numbers
              as noise.
