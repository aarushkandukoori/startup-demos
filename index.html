Small demos, built while reading about a company.

I build tiny, self-contained, working demos while researching companies whose work I find interesting — real logic and real interactivity, running on synthetic data generated in the browser.

Each one is an independent project, built by me with AI assistance and inspired only by a company's public product description. None is affiliated with, endorsed by, or built using private information from any company. Every demo says so on its own page.

This page is not an index, and there is nothing to browse here. Each demo is a separate page with its own direct link, sent to one recipient.
